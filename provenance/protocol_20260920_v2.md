# Evaluation and training protocol revision, 2026-09-20

User authorizes minimal data/runtime adapters and guidance hyperparameter calibration; all official network, loss, optimizer, integration, and sampling implementations remain unchanged. DiffusionPDE is excluded.

OFM training has first priority. Poisson, Helmholtz, Darcy, NS, and Burgers must complete or satisfy the stopping rule before the six added DDIS/FunDPS training queues acquire GPUs. Existing DDIS/FunDPS training continues. ECI evaluation workers avoid GPUs with active OFM training.

Training data: 45,000 cases with the existing aligned split; 5,000 disjoint validation cases. Added DDIS/FunDPS jobs reuse verified compact Darcy/NS/Burgers exports and channel-count-aware HF serialization. FunDPS has no Burgers preset; it uses the official Poisson training hyperparameters with the one-channel Burgers trajectory and official trainer/network. DDIS Burgers explicitly supplies the official CLI channel options missing from its YAML preset. Resource tests run the unchanged official training loop for three updates at batch 1 and the configured batch.

Stopping: after at least 50 equivalent epochs, consider the cumulative improvement in best validation loss over a complete 20-epoch window. Less than 2% improvement triggers a checkpoint-preserving stop. This is stronger evidence than unchanged leading digits in the training loss. The policy applies to current and future tasks, with the old supervisors handled by an external monitor. Future supervisors enforce it internally. Unconditional generation is a separate quality diagnostic, with no sparse observations. Finite images and similar moments alone are not a quality certification.

Evaluation: Poisson/Helmholtz/Darcy/NS use forward and inverse only. Burgers retains the original trajectory-completion task (native config task=both, single solution channel). Each uses ID/Smooth/Rough, first 100 cases, 500 noiseless observations per active field. The matrix specifies 189 method/task/split cells across seven methods. ECI with existing FM4PDE pretrained weights is first priority and runs in independently verified 10-case shards. Ordinary FM and OFM priors use their own training normalizers and noise distributions. Historical two-case outputs are retained unchanged.

Guidance calibration: same-checkpoint Poisson controlled replay changes clipping only, with read-only per-step diagnostics. Hyperparameters are then selected using the first eight validation cases, checked on eight separate validation cases (16:24), and kept separate from ID/Smooth/Rough test cases. The final OFM checkpoint is fixed during each calibration. New settings are promoted only if all held-out cases are finite and no worse than the original setting; otherwise retain a finite original or record needs_review. Calibration includes zeta scaling and global gradient clipping, not algorithm edits.

User subsequently authorized ECI-OFM to start concurrently with ECI-FM. A dedicated worker uses `--eci-ofm-only` and completed OFM best checkpoints, with the same 2,700-case protocol and resource profiling. NS joins automatically after its training completes. Existing ECI-FM workers continue unchanged; this does not wait for FM4PDE-with-OFM guidance calibration, which applies to a different sampler.

User next authorized FM4PDE-OFM concurrently: a dedicated `--fm-ofm-only` worker starts completed priors as soon as their validated guidance settings exist. Diffusion evaluation now waits only for its own prior and (DDIS) auxiliary FNO, not all OFM training or all ECI-FM cases. Active OFM training GPUs remain excluded. FM4PDE-FM4PDE cells are removed from the live matrix: reuse existing results without rerunning. Historical outputs are preserved.
